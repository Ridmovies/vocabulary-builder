# Frontend задание (React)

## Общие требования

* Минимальный функциональный фронт
* Только необходимый функционал, без усложнений
* Опираться строго на backend-контракт

## Источник контракта

* OpenAPI файл: `openapi.json`
* Backend сервер: http://127.0.0.1:8000

Использовать `openapi.json` как единственный источник правды:

---

## Стек

* React + Vite
* TypeScript (строго, без any)
* State: Zustand
* Data fetching: React Query
* UI: без библиотек
* Стили: CSS / CSS Modules

---

## Визуал

* Темная тема
* Основной фон: темно-серый (#121212 или аналог)
* Минимальный интерфейс

---


## Авторизация

* JWT через cookies
* HttpOnly cookies (access + refresh)
* CSRF защита обязательна

### Правила

* все запросы выполняются с `credentials: "include"`
* CSRF токен:

  * брать из cookie
  * передавать в header
* при 401:

  * попытка refresh
  * при неудаче → разлогин

---

## Основная логика

### Регистрация

* после успешной регистрации → автоматический логин
* переход на страницу со словами

### Работа со словами

* получение списка слов
* создание слова

Правило:

* если категория не указана → используется default категория (на backend)
* фронт не должен требовать выбор категории

### Категории

* загрузка списка категорий
* default категория всегда существует

---


## API слой

* использовать `openapi.json`
* не писать лишние абстракции
* использовать React Query для:

  * загрузки данных
  * кэширования

---

## Ограничения

Запрещено:

* Context API для глобального состояния
* избыточные обертки над HTTP
* усложнение архитектуры
* добавление неописанных в OpenAPI сущностей
