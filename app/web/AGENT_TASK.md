# Техническое задание: оптимизация фронтенда (Bootstrap 5) под мобильные устройства + темная тема

## Контекст

Текущая версия:

* Работает корректно
* Использует Bootstrap 5
* Содержит избыточный и неиспользуемый код
* Не оптимизирована под мобильные устройства
* Отсутствует темная тема

---

## Цель

Привести фронтенд к минималистичному, чистому и оптимизированному состоянию с фокусом на мобильные устройства и добавить полноценную темную тему.

---

## Задачи

### 1. Очистка и рефакторинг

Удалить весь неиспользуемый код:

* неиспользуемые HTML-блоки
* тестовые элементы интерфейса
* закомментированные участки
* неиспользуемые JS-функции
* дублирующиеся стили

Упростить структуру:

* минимизировать вложенность DOM
* убрать лишние контейнеры (`div`, `row`, `col`)
* привести классы к единообразию

---

### 2. Оптимизация под мобильные устройства

Сделать mobile-first верстку:

* базовая ширина: 320px–480px
* корректное отображение на всех экранах до desktop

Обязательные требования:

* использовать Bootstrap grid корректно
* исключить горизонтальный скролл
* все элементы должны влезать в экран

Адаптация UI:

* увеличить кликабельные зоны (минимум 44px)
* использовать вертикальные стеки вместо горизонтальных
* уменьшить отступы и размеры текста при необходимости
* формы должны быть удобны для ввода с телефона

Навигация:

* упростить меню
* при необходимости заменить на burger-меню

---

### 3. Внедрение темной темы

Реализовать поддержку dark mode:

Требования:

* использовать CSS переменные (custom properties)
* не дублировать стили напрямую

Пример структуры:

```css
:root {
  --bg-color: #ffffff;
  --text-color: #000000;
}

[data-theme="dark"] {
  --bg-color: #121212;
  --text-color: #ffffff;
}
```

Обновить все элементы:

* background
* текст
* кнопки
* формы
* границы

---

### 4. Переключатель темы

Добавить переключение темы:

* toggle (кнопка или switch)
* сохранение выбора в `localStorage`
* восстановление темы при загрузке страницы

Логика:

```js
const theme = localStorage.getItem("theme") || "light";
document.documentElement.setAttribute("data-theme", theme);
```

---

### 5. Bootstrap 5 интеграция

Проверить корректность использования Bootstrap:

* убрать избыточные классы
* не переопределять Bootstrap без необходимости
* использовать утилиты вместо кастомных стилей, где возможно

---

### 6. Оптимизация CSS и JS

CSS:

* удалить неиспользуемые стили
* объединить дубли
* минимизировать кастомный CSS

JS:

* удалить неиспользуемые скрипты
* убрать console.log
* минимизировать обработчики событий

---

### 7. Производительность

* уменьшить количество DOM-узлов
* сократить размер CSS/JS
* исключить блокирующие скрипты
* проверить загрузку на мобильных сетях

---

## Ограничения

* не изменять API взаимодействия с backend
* не ломать существующую бизнес-логику
* не добавлять тяжелые библиотеки

---

## Ожидаемый результат

* чистый, минималистичный код
* корректная работа на мобильных устройствах
* отсутствие визуальных багов
* реализованная темная тема
* стабильная работа всех существующих функций

---

## Критерии приемки

* интерфейс полностью usable на мобильных устройствах
* нет горизонтального скролла
* темная тема корректно применяется ко всем элементам
* переключение темы работает и сохраняется
* код читаемый и без мусора
